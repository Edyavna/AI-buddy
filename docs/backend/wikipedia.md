# Публичный источник «Авито» и роль AI Buddy

Снимок в `demo/wikipedia/` подготовлен из русскоязычной статьи «Авито» в редакции `155526969` от `2026-10-10T05:13:44Z`. В каталоге лежат Markdown и манифест с контрольной суммой. Участники русскоязычной Википедии указаны в манифесте и в карточке источника. При преобразовании убраны навигация, инфобокс, таблицы, иллюстрации и список примечаний. [Редакция статьи](https://ru.wikipedia.org/w/index.php?title=%D0%90%D0%B2%D0%B8%D1%82%D0%BE&oldid=155526969) · [Лицензия CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

## Импорт

Для поиска по статье запустите сервер с `AI_MODE=live`. Импорт использует `DATABASE_URL`, `EMBEDDING_BASE_URL` и `EMBEDDING_API_KEY`. Загрузчик проверяет SHA-256 нормализованного текста. Идентификатор документа включает номер редакции. Повторный импорт того же снимка сохраняет существующие фрагменты и обходится без запроса эмбеддингов. При первом импорте фрагменты записываются вместе с документом одной транзакцией.

Локально выполните команды из `backend/` после применения миграций.

```sh
go run ./cmd/knowledge-import -wikipedia-dir ../demo/wikipedia
go run ./cmd/knowledge-import -wikipedia-dir ../demo/wikipedia
```

Для Compose выполните команду из корня репозитория.

```sh
docker compose --profile demo run --rm --build knowledge-import /app/knowledge-import -wikipedia-dir /app/wikipedia
```

## Сценарии проверки

Создавайте новый диалог для каждого вопроса. В режиме `demo` доступны ответы о роли. Для истории компании нужен публичный индекс и работающие провайдеры модели и эмбеддингов.

| Вопрос | Ожидаемый результат |
| --- | --- |
| Кто ты? | «Я AI Buddy, помощник по адаптации стажёров в Авито». В демо ответ сообщает о прототипе. |
| Чем ты помогаешь? | Шаги плана, доступы, обращение к наставнику или HR. |
| В какой компании я прохожу адаптацию? | «Авито». Выключенный поиск не влияет на ответ. |
| Когда основали Авито? | Ответ об основании в 2007 году. Карточка «Авито — Википедия» ведёт на редакцию `155526969`. |
| Когда ближайший набор стажёров? | Поиск кадровых материалов. При отсутствии актуального источника агент сообщает о нехватке данных. |
| Когда основали Авито? (эмбеддинги недоступны) | «Поиск публичных сведений об Авито сейчас недоступен. Попробуй позже». |

Браузерный сценарий запускается из корня после запуска приложения с импортированной статьёй. Для воспроизводимого теста можно запустить `node scripts/hr-provider-fixture.mjs` и направить обе настройки `*_BASE_URL` на `http://127.0.0.1:55662`. Используйте тестовые значения ключей. `WIKI_PLAYWRIGHT_MODULE` и `WIKI_BROWSER` задают пути к Playwright и браузеру при локальной установке.

```sh
node scripts/wikipedia-browser.mjs
```
