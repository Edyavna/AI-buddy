# Каталог чекпоинтов

[Таблица адаптации](https://docs.google.com/spreadsheets/d/1qKFqOzfSZ2jEz57jBSmq7rukDXi_tRfWohgemViceV0/edit?gid=1073060303) выгружена в [source.csv](../../backend/internal/checklist/source.csv). В [catalog.json](../../backend/internal/checklist/catalog.json) поле `source_row` нумерует строки с данными с единицы. Заголовки, подпункты и периоды сверяются с экспортом тестом. `template_key` сохраняется при правке текста. Два опроса и две экваторные встречи имеют отдельные ключи.

Роли взяты из [плана #41](https://github.com/Edyavna/AI-buddy/issues/41). В таблице у опросов роль не указана. Назначение первого опроса стажёру, второго наставнику требует подтверждения владельцем контента. Для материалов без проверенных URL указано, где их искать или к кому обратиться.

После применения миграции #42 повторите demo seed командой `docker compose --profile demo run --rm seed`. Он дополняет существующие demo-планы, сохраняет их шаги и связи, добавляет свободного стажёра `intern_demo_unassigned` с отдельным планом. Импорт обновляет метаданные по ключу, оставляет прежний ID и позицию шага и повышает ревизию плана только при изменениях. Для шагов в работе или с завершённым прогрессом сохраняется текущая политика подтверждения. Исключение строки из каталога не удаляет уже выданный шаг.

[Ответ GET плана свободного стажёра](../../contracts/examples/full-demo-plan.json) снят с Go API на чистом seed. Его можно использовать как fixture для #45 и #46. Он содержит все три политики, повторяющиеся заголовки и ресурсы без URL. У существующих стажёров также остаётся прежний шаг «Запустить проект».
