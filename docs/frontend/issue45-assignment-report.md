## Поведение

В существующем /mentor/interns есть «Добавить стажёра». Окно загружает свободных
своей команды, ищет локально по имени и требует явного подтверждения выбранного
стажёра. Выбор сам по себе не отправляет PUT. Показываются загрузка, пустой список,
результат поиска, ошибки и повтор. Обновляются свободные и назначенные.

API использует generated AvailableIntern/MentorAssignment и общий cookie-клиент.
Единственное расширение транспорта — разрешённый метод PUT. Тело, mentor_id,
team_id, Content-Type и дополнительные idempotency/revision не передаются.

409 показывает «Стажёра уже назначили», обновляет оба списка и сбрасывает выбор.
После потери ответа, таймаута, 503/сети или ошибки протокола выполняется свежая
сверка GET /mentor/interns. Успех допустим только при успешной сверке и наличии
стажёра в своём списке. Ошибочная сверка не принимает старый кеш за подтверждение.
Неизвестный исход сохраняет выбранный ID и требует явного повтора того же PUT.
Обычный 200 не требует Plan в ответе. Если плана нет, назначение остаётся успешным;
страница плана обрабатывает 404 с повтором загрузки.

Повторный клик заблокирован. Запросы имеют таймаут 10 секунд и session cancellation;
уход/сброс сессии отменяет транспорт и дальнейшие callbacks, включая поздний ответ
до размонтирования. 401/403/404 очищают связанные списки; последующая 503/сеть не
возвращает данные. Отдельно защищён локальный выбор при неизвестном исходе.
Окно замыкает Tab, закрывается по Escape, восстанавливает фокус на кнопке запуска.

## Настоящий Go без MSW

Проверено в браузере с Vite :5173 и текущим Go server :8080 на dev 11611f2.
Отдельный контейнер ai-buddy-issue45-db, БД buddy_issue45, порт 5545; миграции и
текущий demo seed применены только туда. В тестовую БД добавлены синтетические
intern_demo_unassigned с одним шагом и intern_issue45_no_plan без плана. Это
локальная проверочная фикстура, не изменение общего seed #44.

Через UI: тестовый наставник → стажёры → поиск → выбор → подтверждение → стажёр
исчез из свободных и появился в назначенных → его план доступен → reload сохраняет
назначение/прогресс. Для второго стажёра без плана подтверждён 200 назначения,
0 из 0 шагов в сводке и отдельный 404 плана с повтором. Платный LLM не нужен.

360/768/1440 проверены в браузере: без горизонтального переполнения, Tab/Shift+Tab
остаются в окне, после назначения фокус возвращается к кнопке запуска.
