## Исправления ревью ab2807b

1. usePlan продолжает polling открытого плана при 100%. Опрос скрытой вкладки
   не выполняется, возврат во вкладку сверяет состояние.
2. Отказ доступа завершает предыдущее поколение запросов данного query key.
   GET/PATCH/PUT используют общий сигнал доступа и сессии. Перед записью ответ
   проверяет сигнал; даже транспорт, игнорирующий отмену, не вернёт поздний 200
   в закрытый кеш. Новый успешный GET может восстановить доступ, но не разрешает
   старому PUT заменить новый снимок даже с большей revision.
3. Старый сквозной e2e явно использует одношаговый stateful mock. Его проверка
   «1 из 1, 100%» сохранена; полный каталог из 17 строк проверяется отдельно.

Все три воспроизведения падали до исправления; после исправления проходят.
Защита поколения доступа применяется также к планам кабинета наставника.

## Завершение FE1 #45

Существующие /mentor/interns и /mentor/interns/:id используют общие Step/Plan
schemas из #46. Назначение из первой поставки сохранено. Полный план показывает
периоды, инструкции Markdown/подпункты, материалы, policy, независимые отметки
ролей и время подтверждения, ожидаемого участника и серверные блокировки.
Материал без безопасного http(s) URL не превращается в фиктивную ссылку.

Наставник действует только для mentor/both и по server allowed_actions; intern
остаётся просмотром. Подтверждение и отзыв используют PUT confirmation с revision.
Проценты, количества, статус и следующий шаг — из серверных ответов. Две отметки
both учитываются как один завершённый шаг; отзыв не удаляет отметку стажёра.
После действия обновляется сводка. GET не заменяет более новую версию плана.

Повторный клик блокируется. 409 сверяет план и требует явного повтора. Потеря
ответа/таймаут/503 сверяются отдельным GET: только сохранённая собственная отметка
подтверждает результат. Ошибка сверки явно сообщает неизвестный исход; локальный
оптимистичный успех не применяется. Logout/смена сессии/отзыв доступа отменяют
запросы и запрещают позднюю запись. Сохраняется 401/403/404 → 503 защита кеша.

контракт этой серверной ветки поставляется PR #47. Они пока не находятся в dev.

Go :8080, Vite :5173 без обоих VITE_*_MOCKING флагов, AI_MODE=demo. Синтетические
фикстуры только в этой БД: полный план из 17 строк, полученный из проверяемого
frontend-каталога, и план из трёх шагов intern/mentor/both.

Браузер: две отдельные cookie-сессии localhost (стажёр) и 127.0.0.1 (наставник).
Проверены назначение → полный план → обе последовательности both → один шаг в
прогрессе → отзыв только собственной отметки → сводка → reload. Полный both
после двух отметок дал 1/17 и 5%, не 2/17. Малый план завершился в обоих кабинетах
как 3/3 и 100%. Пока план стажёра оставался открытым и visible, отзыв наставника
через отдельную HTTP-сессию обновил его до 2/3 и 66% без refocus или reload.

Тестовый Go был остановлен и запущен заново, demo seed повторён. Cookie-сессии,
назначения, отметка стажёра и отозванная отметка наставника сохранились; оба
