# #27: поставка 3 — прогресс назначенных стажёров (mock-only)

Ветка feature/mentor-intern-progress продолжает feature/mentor-questions-knowledge.
PR в dev объединять после поставок 1 и 2; при squash предыдущих PR потребуется
rebase. Действующий OpenAPI, generated types, backend, Message/SSE, эскалация и
уведомления не меняются. Согласован только mock-объём, не production mentor API.

Список показывает назначенных стажёров, команду, процент и количество шагов,
блокировки, открытые вопросы и переход к следующему шагу в плане. Значения
берутся из ответа mock-сервера, формула прогресса не меняется. Карточка вопроса
также позволяет открыть план стажёра без вывода внутренних step_id пользователю.

Прямой /mentor/interns/:id загружает существующую схему Plan. Шаги, описания,
состояния и причины блокировок доступны только для чтения. Управления статусами
и перехода в чат от лица стажёра нет. Чужие ID mock-сервер отклоняет 404.
Опрос 5 секунд только на активном экране; скрытая вкладка не опрашивается.
Уход и выход отменяют активные запросы; поздняя мутация не возвращает данные
старого аккаунта в очищенный кеш. 401/403/404 скрывают кешированные планы и имена.
503 оставляет последнее состояние с явной ошибкой обновления и повтором.

Также исправлен разрыв breakpoint кнопки выхода mentor на ширинах 961–1023px;
у списка убраны браузерные маркеры и отступ, сетка адаптируется к контейнеру.
Общие токены и компоненты Авито сохранены, новые зависимости не добавлялись.

Запуск из frontend в PowerShell:

```powershell
npm ci
$env:VITE_MENTOR_MOCKING = 'enabled'
npm run dev
```

Открыть http://localhost:5173/login, выбрать «Тестовый наставник». Навигация:
«Вопросы» → карточка → «Добавить документ» → загрузка .md → готовность → решение;
«Стажёры» → выбранный стажёр → план только для чтения. Для исходного сценария
стажёра выйти и выбрать «Тестовый стажер». Моки существуют только в памяти:
полная перезагрузка сбрасывает сессию/загруженные документы и вопросы.

Vitest/RTL/MSW: серверные счётчики, прямые URL, чужой ID, блокировки, пустой список,
401/403/404 после успешной загрузки, временная 503, отмена запросов при уходе,
отмена мутации и запрет поздней записи после выхода, polling/hidden. Полный набор:
207 тестов, покрытие строк 95,61%; typecheck, lint, check:api и production build.
CI первых двух поставок зелёный, их конфликтов с актуальным dev нет.
