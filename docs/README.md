## Как читать старые отчёты

Документы day-1, delivey, issue*-report, mentor-delivery и каталоги issue*-coverage —
исторические свидетельства отдельных поставок. Их результаты относятся к указанным версиям.
Они не подтверждают покрытие, приёмку или состояние финального объединённого коммита.
Ранние задания по участникам и исходная SDD сохраняются для истории разработки.
Презентация и видео должны ссылаться на окончательную сдаваемую версию.
